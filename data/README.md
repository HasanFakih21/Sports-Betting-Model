# data/

This directory holds all raw and processed data files used by the pipeline.

## raw/

| File | Description |
|---|---|
| `2021-2022.csv` | Premier League season results + Pinnacle odds (Football-Data.co.uk) |
| `2022-2023.csv` | Same format, 2022–23 season |
| `2023-2024.csv` | Same format, 2023–24 season |
| `2024-2025.csv` | Same format, 2024–25 season (partially complete during the season) |
| `all_team_ratings.csv` | FIFA/SOFIFA team ratings per season (Overall, Attack, Midfield, Defence, Players, StartingXI_AvgAge) |
| `understat_team_stats.csv` | Understat season-level xG / xGA / xPTS and W/D/L records per team |

Raw files are **never modified** by any pipeline script.

## processed/

| File | Generated by | Description |
|---|---|---|
| `combined_dataset_clean.csv` | `scripts/data_preprocessing_full.py` | Merged, cleaned dataset ready for model training |
