# results/

Output artefacts generated by `scripts/portfolio_optimization.py`.

## figures/

| File | Description |
|---|---|
| `reliability_home.png` | Reliability diagram comparing raw vs. isotonic-calibrated home-win probabilities |

## logs/

| File | Description |
|---|---|
| `portfolio_simulation_history_restricted_calibrated.csv` | Per-match bet log: predicted outcome, true outcome, Kelly fraction, running wealth |
| `sensitivity_analysis.csv` | Final wealth and risk metrics across fractional Kelly multipliers [0.10, 0.15, 0.20, 0.25] |

> **Note:** These files are generated by the evaluation script and are listed
> in `.gitignore`.  Re-generate them by running:
> ```bash
> python scripts/portfolio_optimization.py
> ```
