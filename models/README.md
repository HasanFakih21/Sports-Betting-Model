# models/

Trained model artefacts saved by `scripts/model_training.py`.

| File | Description |
|---|---|
| `match_outcome_model.keras` | Trained Keras deep neural network (H / D / A classifier) |
| `scaler.pkl` | Fitted `sklearn.preprocessing.StandardScaler` used to normalise features |
| `optimal_temperature.txt` | Single float — optimal temperature *T* for post-hoc temperature scaling |

> **Note:** These files are generated by the training script and are listed in
> `.gitignore`.  Re-generate them by running:
> ```bash
> python scripts/model_training.py
> ```
