# Sports Betting Model

A machine-learning pipeline that predicts Premier League match outcomes (Home
win / Draw / Away win) and simulates a calibrated, risk-managed betting strategy
using the fractional Kelly criterion.

## Project overview

The model combines three data sources:

| Source | What it provides |
|---|---|
| **Football-Data.co.uk** season CSVs | Match results + Pinnacle closing odds |
| **FIFA / SOFIFA team ratings** | Overall, Attack, Midfield, Defence ratings per season |
| **Understat** xG stats | xG, xGA, xPTS and season-level records per team |

A deep neural network is trained using expanding-window cross-validation
(respecting the temporal ordering of matches), then calibrated with both
temperature scaling and isotonic regression before being used to size bets via
a restricted fractional Kelly strategy.

## Quick start

### 1. Clone & install dependencies

```bash
git clone https://github.com/HasanFakih21/Sports-Betting-Model.git
cd Sports-Betting-Model
pip install -r requirements.txt
```

### 2. Run the pipeline (from the project root)

```bash
# Step 1 – merge and clean raw data
python scripts/data_preprocessing_full.py

# Step 2 – train the model (saves artefacts to models/)
python scripts/model_training.py

# Step 3 – evaluate calibration and simulate betting strategy
python scripts/portfolio_optimization.py

# Optionally specify a different test season:
python scripts/portfolio_optimization.py --season 2023-2024
```

> **Note:** All three scripts resolve paths relative to themselves, so they
> can be run from any working directory.

## Pipeline walkthrough

### Step 1 – Data preprocessing (`data_preprocessing_full.py`)

* Loads the four season CSVs and keeps only the relevant columns (date, teams,
  goals, full-time result, Pinnacle odds).
* Normalises team names to a canonical lowercase form using a mapping dictionary.
* Left-joins FIFA team ratings and Understat xG statistics for both the home
  and away team in each match (keyed on Season + team name).
* Writes the merged, cleaned dataset to `data/processed/combined_dataset_clean.csv`.

### Step 2 – Model training (`model_training.py`)

* Drops the first week of each season to avoid early-season instability.
* Scales features with `StandardScaler` (saved to `models/scaler.pkl`).
* Runs an L1 logistic regression for informational feature selection.
* Performs expanding-window (rolling) cross-validation with 10% fold sizes.
* Trains a 4-hidden-layer deep neural network with Batch Normalisation and
  Dropout on all available data with an EarlyStopping + ReduceLROnPlateau schedule.
* Finds the optimal temperature *T* for post-hoc temperature scaling on the
  last 10% of chronologically sorted data.
* Saves `models/match_outcome_model.keras`, `models/scaler.pkl`, and
  `models/optimal_temperature.txt`.

### Step 3 – Portfolio optimisation (`portfolio_optimization.py`)

* Loads the test season (default: `2024-2025`).
* Generates MC Dropout ensemble predictions (20 forward passes).
* Fits per-class isotonic regression calibrators on a 30% calibration split.
* Evaluates Brier scores and plots a reliability diagram
  (`results/figures/reliability_home.png`).
* Simulates a **restricted fractional Kelly** strategy using calibrated
  probabilities and Pinnacle closing odds.
* Runs a sensitivity analysis across fractional multipliers [0.10, 0.15, 0.20, 0.25].
* Saves simulation history and sensitivity results to `results/logs/`.

## Model architecture

```
Input (36 features)
  → Dense(256, relu) → BatchNorm → Dropout(0.4)
  → Dense(128, relu) → BatchNorm → Dropout(0.4)
  → Dense(64,  relu) → BatchNorm → Dropout(0.3)
  → Dense(32,  relu) → BatchNorm → Dropout(0.2)
  → Dense(3, softmax)   # [P(H), P(D), P(A)]
```

* **Optimiser:** Adam (lr = 0.0005) with ReduceLROnPlateau
* **Loss:** Categorical cross-entropy
* **Labels:** Encoded with a fixed canonical order H → D → A to ensure
  consistency across train/calibration/evaluation splits.

## Calibration & betting strategy

### Temperature scaling
Finds the scalar temperature *T* ∈ [0.5, 5.0] that minimises log-loss on a
held-out calibration set by dividing the penultimate-layer logits by *T* before
softmax.

### Isotonic regression (one-vs-all)
A monotone isotonic regressor is fitted per outcome class on a 30% subset of
the test season, then applied to the evaluation set.

### Restricted fractional Kelly
For each match the Kelly fraction is computed per outcome and scaled down by a
fractional multiplier (default: 0.25) to limit variance.  Only the outcome with
the highest positive Kelly fraction receives a bet.

```
f* = frac_mult × ( p − 1/o ) / ( o − 1 )
```

where *p* is the calibrated model probability and *o* is the decimal odds.
